# UX/UI

Diseño administrativo-financiero minimalista y original basado en patrones de apps modernas: superficies claras, jerarquía fuerte, verde de interacción, bordes suaves, estados explícitos y responsive mobile-first. No copiar identidad, logotipos, textos o assets de World Money, ChatGPT o MoonPay.

Flujo: Captar → Interpretar → Normalizar → Validar → Revisar → Autenticar → Generar → Verificar → Auditar.

Componentes: SmartField, ConditionalSection, ProgressIndicator, ValidationMessage, ReviewPanel, AuthSheet, VerificationCard, AuditTimeline.
